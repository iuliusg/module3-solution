Module 3 solution — required portion

Open index.html in a browser. An internet connection is needed to load
Bootstrap 3.4.1 and jQuery from their CDNs.

This implements the required single-section version. Beef and Sushi are
placeholder menu links; the assignment does not require them to navigate.

To submit: copy the module3-solution folder into your course repository,
publish that repository with GitHub Pages, and submit the URL ending in
/module3-solution/ . A local file path cannot be submitted as a public URL.

Check at desktop, tablet, and mobile widths. Below 768px, open and close
the navigation button. Scroll down to confirm the navbar scrolls away.
